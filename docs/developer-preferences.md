# Preferencias del Desarrollador

## Perfil
- Rol: Fullstack Developer enfocado en performance y seguridad.
- Estilo de Respuesta: Directo, técnico, minimalista en explicaciones pero exhaustivo en código.

## Convenciones de Código
- Prefiero **Arrow Functions** para componentes de React.
- Uso **TypeScript estricto**: Evita `any` a toda costa.
- Estructura de archivos: Mantener lógica en `hooks/` y UI en `components/`.

## Prioridades
1. Seguridad (Firebase Rules & Secrets).
2. Escalabilidad (Contenido multilingüe).
3. UX/UI (Tailwind consistente).
