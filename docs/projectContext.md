# Project Context: House-Portal-OS

## 📋 Overview
`House-Portal-OS` is a professional-grade Monorepo designed as a central hub for various specialized applications. It serves as an internal "Operating System" for business management (Mini-ERP), food ordering, service management, interactive games, and an AI bot (Telegram/WhatsApp).

## 🏛️ Repository Structure
- **`/apps`**: 10 applications (house-menu, househub, worker-portal, 26play, sorteos-automaticos, house-cleaning, house-laundry, portal-hub, housepysbot, piramid-game).
- **`/packages`**: 4 shared packages (@house/ui, @house/tokens, @house/db, @house/store).
- **`/agents`**: AI agent skills (Clean Minimalist Designer skill).
- **`/docs`**: Permanent Context Engineering documentation.
- **`/scripts`**: Implementation tools.
- **`/design-system`**: Clean Minimalist prototype & demo.

## 🎯 Primary Goals
1..  **Uniformity**: Todos los frontends comparten el mismo Design System (Clean Minimalist via `@house/tokens`).
2.  **Professionalization**: Código tipado, estructurado, con workspaces npm.
3.  **Automation**: AI Bot (housepysbot) maneja atención al cliente y administración vía Telegram/WhatsApp.
